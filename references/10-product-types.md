# Product Types and Visual Directions

## Six Personality Axes

Pick a position on each axis. The combination defines a direction that is hard to confuse with the default.

| Axis | Pole A | Default (Slop) | Pole B |
|---|---|---|---|
| **Tone** | Playful, warm | Neutral, corporate | Serious, austere |
| **Density** | Dense, information-rich | Medium, balanced | Sparse, airy |
| **Structure** | Organic, asymmetric | Centered, symmetrical | Rigid, grid-locked |
| **Color** | Warm, earthy | Cool, blue-purple | High-contrast, bold |
| **Typography** | Expressive, display | Sans-serif, safe | Editorial, serif |
| **Motion** | Lively, bouncy | Subtle fade-in | Precise, snappy |

The default position on every axis is the statistical center. Choosing any non-default position on at least three axes creates a direction.

## Category Starting Positions

### Developer Tools / API Products

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Serious, precise | Developers value accuracy over warmth |
| Density | Dense | Information-rich interfaces for power users |
| Structure | Rigid, grid-locked | Code and data love grids |
| Color | Cool, muted | Technical, not playful |
| Typography | Monospace body, sans display | Code is central; hierarchy through weight |
| Motion | Precise, snappy | Fast feedback loops |

**Example direction:** "Technical precision — dense monospace body, cool neutrals, grid structure, snappy motion, weight-based hierarchy."

### SaaS Dashboard / B2B Product

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Neutral, confident | Professional without being cold |
| Density | Medium-high | Data density balanced with scannability |
| Structure | Rigid, organized | Predictable layouts reduce cognitive load |
| Color | Muted with one sharp accent | Status and priority need color |
| Typography | Clean sans-serif, clear scale | Readability at small sizes |
| Motion | Subtle, functional | Motion communicates state changes |

**Example direction:** "Confident utility — clean sans, muted palette with one alert accent, organized grid, functional motion, dense but scannable."

### Consumer Mobile App

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Playful, warm | Consumer apps compete on delight |
| Density | Sparse to medium | Touch needs space; one task per screen |
| Structure | Organic, bottom-weighted | Thumb zones, natural flow |
| Color | Warm or bold | Personality and brand recognition |
| Typography | Friendly sans, generous scale | Readability at arm's length |
| Motion | Lively, responsive | Touch feedback and transitions |

**Example direction:** "Friendly confidence — warm rounded sans, generous spacing, bold accent color, bottom-weighted actions, responsive motion."

### Editorial / Content / Publishing

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Serious, warm | Respect for content, not cold distance |
| Density | Sparse | Content needs room to breathe |
| Structure | Asymmetric, editorial | Visual interest supports the reading |
| Color | Warm neutrals, one ink color | Paper-like, typographic |
| Typography | Serif body, expressive display | Reading is the product |
| Motion | Minimal, precise | Do not distract from the content |

**Example direction:** "Editorial warmth — serif body, warm paper-like neutrals, asymmetric layouts, minimal motion, typographic hierarchy."

### E-commerce / Retail

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Warm, confident | Trust + enthusiasm |
| Density | Medium | Products need space; categories need density |
| Structure | Flexible grid | Products vary in aspect ratio |
| Color | Brand-forward, bold CTA | Conversion depends on clear actions |
| Typography | Clean sans, clear hierarchy | Scanning and decision-making |
| Motion | Functional + delight | Load products, celebrate purchase |

**Example direction:** "Confident retail — clean sans, brand-dominant palette with bold CTA, flexible product grid, functional motion with purchase delight."

### Fintech / Banking

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Serious, trustworthy | Money demands gravity |
| Density | Medium | Information without overwhelm |
| Structure | Rigid, organized | Predictability builds trust |
| Color | Deep, muted with one positive/negative accent | Status needs clarity |
| Typography | Clean sans, tabular numbers | Accuracy in figures |
| Motion | Precise, minimal | Stability, not playfulness |

**Example direction:** "Trustworthy precision — clean sans with tabular figures, deep muted palette, organized structure, minimal motion, clear status colors."

### Healthcare / Wellness

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Warm, calm | Anxiety reduction |
| Density | Sparse to medium | Clarity for stressed users |
| Structure | Organic, flowing | Natural, human feel |
| Color | Soft, warm | Comfort and care |
| Typography | Rounded sans, generous | Approachability |
| Motion | Gentle, soothing | Calm transitions |

**Example direction:** "Calm care — rounded sans, soft warm palette, flowing organic layouts, gentle motion, generous whitespace."

### Creative / Portfolio / Agency

| Axis | Suggested Position | Rationale |
|---|---|---|
| Tone | Expressive, bold | Demonstrate creative capability |
| Density | Variable by section | Show range |
| Structure | Asymmetric, experimental | Break expectations |
| Color | Bold or deliberately restrained | Make a statement either way |
| Typography | Expressive, mixed | Typography as image |
| Motion | Artful, purposeful | Motion as expression |

**Example direction:** "Bold expression — mixed typefaces, high-contrast or near-monochrome, asymmetric compositions, artful motion, density that varies by intent."

## Committing to a Direction

1. Identify the product category. Match to the closest entry above.
2. Read the suggested positions. These are starting points, not rules.
3. Adjust for the specific product.
4. Name the direction in one sentence: "[Adjective] [noun] — [key choices]."
5. The named direction is what prevents regression to the mean.

### Example Commitments

- "Editorial warmth — serif body, warm neutrals, asymmetric layouts, minimal motion."
- "Technical precision — monospace body, cool neutrals, grid structure, snappy motion."
- "Friendly confidence — rounded sans, bold accent, generous spacing, lively motion."
- "Trustworthy precision — tabular figures, deep palette, organized structure, minimal motion."
